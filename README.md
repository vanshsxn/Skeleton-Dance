# 🦴 AI Skeleton Dance Generator

**Transform ordinary dance videos into glowing AI-powered skeleton animations!**

AI Skeleton Dance Generator is a computer vision project that uses YOLO Pose Estimation and OpenCV to detect human body movements, extract keypoints, and generate a glowing cyan skeleton animation on a pure black background.

## 🚀 Features

- Human pose detection using YOLO.
- Extraction of 17 human body keypoints.
- Human movement tracking using ByteTrack.
- Smooth skeleton movement using temporal smoothing.
- Glowing neon skeleton effects.
- Black background with skeleton-only output.
- MP4 video generation and download.
- Google Colab compatibility.

## 🛠️ Technologies Used

- Python
- Ultralytics YOLO Pose
- OpenCV
- NumPy
- ByteTrack
- Google Colab

## ⚙️ How It Works

1. Upload a dance video.
2. YOLO detects the human body.
3. Extract 17 body keypoints.
4. Track joint movements across frames.
5. Generate a glowing skeleton animation.
6. Export the final video in MP4 format.

## ▶️ Getting Started

1. Open Google Colab.
2. Create a new notebook.
3. Copy the project code into a cell.
4. Run the code and upload your dance video.
5. Wait for processing to finish.
6. Preview and download your skeleton dance video.

## 🎯 Project Objective

The main objective is to demonstrate how Artificial Intelligence and Computer Vision can be used to understand human movements and convert real-world dance videos into digital skeletal animations.
